# Documents (optional)

Files placed here get a "Download" button automatically; the button stays hidden until the file exists.

- `ps1.pptx` — Problem Statement 1 deck (button on /work/ps1)
- `ps2.pptx` — Problem Statement 2 deck (button on /work/ps2)
- Your résumé — set its path in `assets/js/config.js` → `resume: "docs/your-file.pdf"`

Note: PowerPoint files with many photos can be large. Vercel serves static files fine, but compress decks
(File → Compress Pictures in PowerPoint) if a file is above ~25 MB.
